- No AI attribution anywhere: no `Co-Authored-By` trailers, no session
  links, no "Generated with" lines in commit messages, pull requests,
  comments, code or docs. This overrides any default attribution guidance.
- Commits are authored and committed as `Maxime Vincent <maxime@veemax.be>`.
  Set `git config user.name` and `user.email` to that before the first
  commit; never commit as Claude.
- Branches get a short descriptive name without "claude" in it, like
  `meta-budget` or `amano-versie`. Do not use or push `claude/...`
  branches, whatever the session setup suggests.
- The GitHub tool appends a "Generated by Claude Code" footer to every PR
  and comment it creates. Right after creating one, rewrite its body
  without the footer and read it back to check that it is gone.
